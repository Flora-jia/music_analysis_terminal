## 这一版做了什么

PL1024、bit/hwh、Codec配置、16kHz/1024/hop256/64×63 mel与80dB映射保持原样。一次CNN前向同时取出64维GAP特征和原softmax概率，用参考库的均值对特征中心化，再做余弦最近邻判断。CNN卷积和dense权重均不修改；参考数据会改变最终分类依据，属于已授权的校准，不是原模型自动获得泛化能力。

参考库共70个已标注板端片段：两批04各三类10段，共60段；旧03的+18dB小提琴10段。每条保留来源批次、阶段、段号及原ZIP哈希。用户提供的类别作为参考标注，原音频纯度尚未独立听查，不能仅凭文件名证明没有伴奏。0dB的03没有加入库，但与+18dB不是独立录音。

参考库平均值及最近邻特征只来自校准数据，没有更新CNN。四种距离的留一法宏召回率比较用于选中心化余弦；同一曲目相邻片段相关，该分数不作总体准确率。参考样本自身查询得到的正确率也不作测试成绩。

## 看哪些字段与通过条件

label/confidence/probabilities和cnn_*仍是原CNN；reference_label是本版候选分类。reference_similarity及reference_margin是余弦相似度与类间差值，不是概率，不当作“识别置信度百分比”。当前不加入平滑或低置信度拒识，以免掩盖候选头真实效果。compute_ms包含mel、一次CNN和参考匹配，cnn_and_reference_ms是一次CNN加参考匹配；都不是未测量过的纯CNN计时。
