## 训练方法与验证

三层卷积冻结，使用已有70条参考embedding作为25%权重的旧样本回放，保护既有特征空间；手机现场样本占75%权重，按类别/源音频均衡。
仅优化Dense的64×3权重与3个偏置。训练内部做特征标准化，最终已折叠回原有权重/偏置，部署不增加标准化层，不改变推理接口。
固定800步Adam、标准化坐标学习率0.02、向原头部参数L2约束0.001、标签平滑0.02。不是全网络TensorFlow训练。

按五个音高分组留出验证：每次将一个音高在三个类别中的全部片段留出，包含同一文件重复播放；其余音高训练。没有把相邻帧随机拆分。超参数在回归检查前固定，没有根据各留出组调参。
