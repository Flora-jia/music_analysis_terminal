# 特征契约与辅助提示词

复用时逐项填写：输入单位/符号/位宽；采样率；N、hop、实际窗长；periodic/symmetric窗；center与pad_mode；帧数及截断/补齐；FFT输出顺序；缩放/BFP定义；幅度或功率；量化小数位；mel矩阵文件及哈希；若重新生成矩阵则需htk/norm/fmin/fmax；log底数、参考范围、top-dB/clip、dtype；静音门控；模型权重及类别顺序。

不能先用默认训练库参数“猜测一致”。误差定位顺序：PCM/窗口→FFT/谱→指数恢复→mel→归一化→模型概率。每层对照用同一输入，注明位准确还是近似数值容差。

提示词模板（本次整理，稳定性尚未单独评估）：
> 从【训练预处理代码】和【PL/PS实现】提取逐字段契约，列出未知项。生成同一输入的逐层数组参考与比较命令，容差按格式推导。先定位第一处偏差，不同时更换窗口、缩放、归一化和模型。将“数值回放通过”与“独立音源识别通过”分别报告，并验证错误指数/有符号误读/错矩阵确实被发现。
