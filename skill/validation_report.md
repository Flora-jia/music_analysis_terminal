## 执行与复核

在skill目录执行：

```bash
python -B tests/validate_layout.py
python -B tests/run_skill_tests.py --out your_unit_run
python -B tests/replay_examples.py --out your_example_run
python -B tests/verify_skill_package.py
```

输出目录必须全新。本次机器：Windows 11、Python3.12.14、NumPy2.3.5。脚本目标Python3.8+；NumPy函数要求1.20+，未逐一实测所有版本。主机MMIO对象是模拟对象，测试不会下载bit、改寄存器或连接JTAG。

官方技能快速校验器已尝试执行，但当前打包Python没有PyYAML，导入失败。没有伪造其通过结果；已提供且执行 tests/validate_layout.py，以无外部依赖方式验证本包实际使用的name/description两字段及必要文件。这不是一个完整YAML解析器，不接受任意新增嵌套元数据。
